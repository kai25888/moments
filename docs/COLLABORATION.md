│  └─────────────────────────────────────────────────────────────┘ │

## 二、接口约定

### 2.1 图片上传接口

**接口**: `POST /api/file/upload`

**请求**: `multipart/form-data`
```
files: [file1, file2, ...]
```

**响应**:
```json
{
  "code": 0,
  "data": [
    {
      "url": "/upload/abc123_1200w.webp",
      "thumbUrl": "/upload/abc123_600w.webp"
    }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | ✅ | 大图 URL (Fancybox 查看用) |
| thumbUrl | string | ✅ | 缩略图 URL (列表展示用) |

### 2.2 获取 Memo 列表接口

**接口**: `GET /api/memo/list`

**响应**:
```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "content": "...",
        "imgs": "/upload/a.webp,/upload/b.webp",
        "imgConfigs": [
          { "url": "/upload/a_1200w.webp", "thumbUrl": "/upload/a_600w.webp" },
          { "url": "/upload/b_1200w.webp", "thumbUrl": "/upload/b_600w.webp" }
        ]
      }
    ]
  }
}
```

### 2.3 图片命名规范

| 后缀 | 尺寸 | 用途 |
|------|------|------|
| `_300w` | 宽度 300px | 头像、小图标 |
| `_600w` | 宽度 600px | 列表预览 (必须) |
| `_1200w` | 宽度 1200px | 弹窗大图 |
| `_orig` | 原始尺寸 | 原图存档 (可选) |

> **注意**: 图片统一转为 WebP 格式
