## 二、前端优化方案

### 2.1 ImageLazy 组件设计

```vue
<ImageLazy
  :src="originalUrl"           <!-- 原图 URL (查看大图时用) -->
  :thumb-src="thumbUrl"         <!-- 🔥 缩略图 URL (列表优先加载) -->
  format="webp"                 <!-- 图片格式 -->
  quality="80"                  <!-- 图片质量 -->
  aspect-ratio="1/1"            <!-- 维持宽高比 -->
  :lazy="true"                  <!-- 是否懒加载 -->
/>
```

### 2.2 图片加载优先级

```
1. 缩略图 (thumbSrc) → 列表展示，优先加载
2. 原图 (src) → 骨架屏动画 → 缩略图 → 点击查看
3. 大图 (Fancybox) → 用户点击后加载 1200w
```

### 2.3 懒加载逻辑

- 使用 IntersectionObserver，滚动到可视区域前 200px 开始加载
- 骨架屏动画提升用户体验
- 缩略图加载失败自动降级到原图

## 三、后端需要配合的接口

### 3.1 上传接口改造

**文件**: 后端 `file.go` - Upload 函数

**当前返回**:
```json
["/upload/abc123.jpg"]
```

**期望返回**:
```json
[{
  "url": "/upload/abc123.webp",
  "thumbUrl": "/upload/abc123_600w.webp"
}]
```

### 3.2 获取 Memo 列表接口

**文件**: 后端 memo 相关接口

**期望 ImgConfig 结构**:
```typescript
interface ImgConfig {
  url: string;       // 原图/大图 (Fancybox 查看)
  thumbUrl: string;  // 🔥 缩略图 (列表展示用)
}
```

### 3.3 图片命名规范

| 尺寸 | 用途 | 示例 |
|------|------|------|
| 300w | 头像、小图标 | `abc123_300w.webp` |
| 600w | 列表预览 (推荐) | `abc123_600w.webp` |
| 1200w | 弹窗大图 | `abc123_1200w.webp` |
| orig | 原图存档 | `abc123_orig.webp` |

## 八、常见问题

### Q: 前端没有 thumbUrl 怎么办？
A: ImageLazy 会自动降级到 `src` 属性加载原图，缩略图优化暂不生效。

### Q: 后端还没转 WebP 怎么办？
A: ImageLazy 的 `format` 属性设置为 `original`，保持原格式加载。

### Q: 已有图片如何处理？
A: 见 `ARCHITECTURE.md` 章节 "七、注意事项" - 现有图片批量转码方案。
